These tools are registered with document.modelContext.registerTool(). To let a real agent drive this page:
  1. Open chrome://flags/#enable-webmcp-testing in Chrome 149+, set it to Enabled, and relaunch.
  2. Serve this file over HTTP — npx serve . — since WebMCP needs an origin-isolated document and won't run from file://.
  3. Install the Model Context Tool Inspector extension, or open the page in ChatGPT's in-app browser, and ask for a seating plan in plain language.
